📘 About This Project

This project simulates a web browser's history management system using Stack Data Structure. It demonstrates how modern browsers implement navigation like BACK and NEXT efficiently.

🔧 Technologies Used:

  • Flask (Python) – backend logic
  • HTML, CSS – UI design
  • Stack (LIFO) – history management

⚙️ Working:

  • Back Stack → stores visited pages
  • Forward Stack → stores next pages
  • New visit clears forward stack

🎯 Purpose:

  • Understand Stack Data Structure practically
  • Simulate real-world browser behavior
  • Apply DSA concepts in real applications
